D-118 UX Prototype — Design Notes

1. Readiness Stepper replaces the old "3/7 enrichments applied" progress bar. It shows the model's actual maturity state computed from content, with tooltips explaining each level and a hint for advancing.

2. NBA Recommendation sits above both sections as a gentle suggestion, never a gate. The user can ignore it and run any available operation.

3. Two-zone layout (Enrichments / Diagnostics) replaces the old five-category grouping. The semantic split matches D-118's fundamental distinction: enrichments modify, diagnostics assess.

4. Staleness is shown by desaturating the entire card (CSS opacity + saturate filter) with an amber banner explaining what happened and offering Re-run. This is the "visible-but-desaturated" compromise from D-118 — not hidden, not full-fidelity.

5. Soft blocks show "Run Anyway" as a subtle secondary button. Never hard-blocked. Plausible Over Perfect.

6. External Inputs panel is collapsible at the top — project-level assets that persist across scaffold versions. Individual cards show "Using: SWOT Analysis" when inputs are present, or "Tip: Add a Strategic Plan" as a gentle nudge.

7. Layer badges (Structural / Diagnostic / Interpretive) give advanced users ontological context without cluttering the UI for beginners.

8. Progressive disclosure — operations further from readiness are more dimmed. "Coming Soon" operations are visible but clearly deferred. The page tells a story of where you are and where you're heading.
